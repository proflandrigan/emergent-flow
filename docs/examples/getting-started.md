# Getting Started

Emergent Flow is a visual data/ML platform: a Python SDK (`emergentflow`, conventionally
aliased `ef`) for building and compiling data/ML pipelines as a graph IR, paired with a local
React canvas for building the same pipelines visually. This guide gets you from a fresh
install to your first pipeline running both ways — in Python and in the canvas.

## 1. Installation

```bash
pip install emergentflow              # SDK only
pip install 'emergentflow[server]'    # SDK + canvas server
# or from source:
uv sync --locked
```

A bare `pip install emergentflow` gives you the SDK for programmatic/scripted use. The
`[server]` extra adds FastAPI/Uvicorn so you can also run the visual canvas
(`emergentflow serve`, below). If you're working from a clone of this repo, `uv sync --locked`
installs the pinned dev environment (SDK + server + test/lint tooling) in one step.

## 2. Your First Pipeline (SDK)

Emergent Flow bundles a few small sample datasets (from scikit-learn) so you can try things
out with zero files on disk:

```python
import emergentflow as ef

# Load a bundled sample dataset (no files needed)
df = ef.data.load_sample("iris")
print(df.head())
```

```
   sepal length (cm)  sepal width (cm)  petal length (cm)  petal width (cm)  target
0                5.1               3.5                1.4               0.2       0
1                4.9               3.0                1.4               0.2       0
2                4.7               3.2                1.3               0.2       0
3                4.6               3.1                1.5               0.2       0
4                5.0               3.6                1.4               0.2       0
```

`load_sample` also accepts `"wine"` and `"diabetes"`; each returns a tidy DataFrame with its
feature columns plus a `target` column.

Now chain a few operations over that DataFrame — summarize it, look at correlations, plot it,
and train a classifier:

```python
# Summarize
summary = ef.stats.describe(df)
print(summary)

# Compute correlations
corr = ef.stats.correlation(df)

# Visualize
plot = ef.viz.plot(
    df,
    chart="scatter",
    encoding={"x": "sepal length (cm)", "y": "petal length (cm)", "color": "target"},
)

# Train a classifier
result = ef.ml.train_classifier(df, target="target")
print(f"Accuracy: {result.accuracy:.2%}")
print(f"Classes: {result.classes}")
```

```
Accuracy: 97.37%
Classes: ['0', '1', '2']
```

`describe` and `correlation` each return a tidy `pandas.DataFrame`; `plot` returns a
JSON-native `PlotSpec` (a serialized Plotly figure — this is what the canvas renders, and what
you'd embed in a report). `train_classifier` fits a logistic regression under the hood and
returns an inspectable `ClassifierResult` — never the live scikit-learn estimator — with
`accuracy`, `classes`, `feature_names`, and `coefficients` fields.

## 3. Compile & Execute a Graph

Everything above ran functions directly. The other way to drive Emergent Flow is through its
graph IR — a JSON document describing nodes and edges — which two pure functions both accept:

```python
import emergentflow as ef
from emergentflow.ir.serialize import load_graph

# Load a graph definition
graph = load_graph("examples/functional_pipeline.json")

# Execute in-process
results = ef.execute(graph)

# Or compile to a standalone Python script
code = ef.compile_to_code(graph)
print(code)  # runnable Python module
```

`compile_to_code(graph)` emits a self-contained module built entirely from `ef.*` calls:

```python
"""Generated by Emergent Flow. Do not edit by hand."""

import emergentflow as ef


def main() -> dict[str, object]:
    load_csv_frame = ef.data.load_csv("examples/vertical_slice/sample.csv", encoding="utf-8")
    impute_missing_frame = ef.clean.impute_missing(load_csv_frame, strategy="median", columns=None)
    anova_result = ef.stats.anova(
        impute_missing_frame, group_col="cohort", value_col="score", alpha=0.05
    )
    return {"anova_result": anova_result}


if __name__ == "__main__":
    _results = main()
    for _name, _value in _results.items():
        print(f"{_name} = {_value!r}")
```

`execute(graph)` and `compile_to_code(graph)` are equivalent by design
([ADR 0002](../adr/0002-execute-the-ir-not-the-string.md)): running the code that
`compile_to_code` emits produces the same results as `execute`'s in-process interpreter. This
is enforced as a CI gate, so you can pick whichever fits your workflow — `execute` for quick
iteration, `compile_to_code` when you want a standalone script to check into version control,
schedule, or hand to someone without Emergent Flow installed.

## 4. Launching the Canvas

```bash
emergentflow serve                    # opens browser at http://127.0.0.1:8765
emergentflow serve --no-browser       # headless
emergentflow lab                      # alias for serve
```

Verify it's running:

```bash
curl http://127.0.0.1:8765/healthz    # {"status":"ok"}
```

The canvas has three panels: a **palette** on the left (search or click a node type to add it
to the graph), the **canvas** in the center (drag from a node's output port to another node's
input port to connect them), and an **inspector** on the right (tabs for the selected node's
config, generated code, and last execution's results). See the
[Canvas UI Guide](canvas-ui-guide.md) for the full walkthrough.

> **In the Canvas:** The same pipeline above can be built visually — add a `load_sample` node,
> connect it to a `describe` node, then to a `train_classifier` node. Click **Execute** in the
> toolbar to run the whole graph. See [Canvas UI Guide](canvas-ui-guide.md) for details.
